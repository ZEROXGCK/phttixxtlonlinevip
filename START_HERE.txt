📋 INSTALLATION CHECKLIST
================================================================================

Before Installation:
  ☐ Ubuntu 22.04/24.04/26.04 on VPS
  ☐ Domain with A record pointing to VPS IP
  ☐ Root or sudo access to VPS
  ☐ Outbound port 443 allowed (for SSL)
  
During Installation:
  ☐ Run xxtlonline-setup.sh
  ☐ Enter domain name
  ☐ Enter 3x-ui admin password
  ☐ Choose IPv4/IPv6 preference
  ☐ Wait 5-10 minutes
  
After Installation:
  ☐ Access dashboard: https://panel.yourdomain.com
  ☐ Create first SSH user
  ☐ Test SSH connection
  ☐ Create backup: sudo xxtlonline-utils.sh backup
  ☐ Verify all services: sudo xxtlonline-utils.sh status

📊 WHAT GETS INSTALLED
================================================================================

Component              Port        Purpose
─────────────────────────────────────────────────────────────────────────────
OpenSSH                22          Standard SSH (pre-existing)
WS-Stunnel             80          HTTP-CONNECT tunnel (port 80)
Dropbear SSH           143, 109    Lightweight SSH server
3x-ui v2.9.4          54321       VLESS/VMess proxy panel
3x-ui Dashboard       443, 2503    Web UI dashboard + reverse proxy
BadVPN UDP Gateway     7300        UDP relay (localhost only)
SSH API                6789        REST API (localhost only)

All services are auto-started and monitored by systemd.

================================================================================
🔐 SECURITY NOTES
================================================================================

✅ INCLUDED BY DEFAULT:
  • SSL/TLS certificate (auto via Certbot)
  • Firewall configuration (UFW)
  • SSH hardening
  • 1M+ file descriptor limit
  • Network tuning (BBR, FQ, RPS/RFS)

⚠️  IMPORTANT:
  • SSH API (port 6789) is localhost-only
  • Change admin password after first login
  • Keep backups in safe location
  • Review firewall rules regularly
  • Rotate SSH user passwords quarterly

🔒 OPTIONAL HARDENING:
  • SSH key authentication (see README.md)
  • Disable password login (not recommended for SSH tunnels)
  • Set up monitoring/alerts
  • Enable 2FA on admin panel

================================================================================
📈 SYSTEM REQUIREMENTS
================================================================================

Minimum:
  • 1 GB RAM
  • 5 GB disk space
  • Ubuntu 22.04 / 24.04 / 26.04
  • Public IPv4 address

Recommended:
  • 2 GB+ RAM
  • 10 GB+ disk space
  • Ubuntu 24.04 LTS (stable, long support)
  • Static IP (not required but helpful)

Not Supported:
  • Shared hosting
  • OpenVZ (no full network stack)
  • No root access
  • Network-restricted (port 443 blocked)

✅ VERIFICATION AFTER INSTALLATION
================================================================================

1. Dashboard accessible:
   $ curl -I https://panel.yourdomain.com
   → Should return: HTTP/2 200 OK with security headers

2. All services running:
   $ sudo xxtlonline-utils.sh status
   → All should show as "active"

3. SSH API responding:
   $ curl http://localhost:6789/api/status
   → Should return JSON with connection count

4. SSL certificate valid:
   $ sudo certbot certificates
   → Should show certificate for your domain

If any checks fail, run diagnostics:
   $ sudo xxtlonline-utils.sh diagnostics
